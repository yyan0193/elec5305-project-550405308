# Interpretable Classification of Traditional Chinese Musical Instruments Using Timbral Audio Features

**Student:** Yuxuan Yang
**SID:** 550405308
**Course:** ELEC5305

## Project Overview

This project aims to identify eleven traditional Chinese musical instruments from short audio clips using MATLAB. It will reproduce the MFCC-KNN baseline from the ChMusic dataset and extend it with interpretable spectral and temporal audio features.

## Method

* Audio preprocessing and five-second segmentation
* MFCC feature extraction
* KNN classification with majority voting
* Interpretable timbral features
* Evaluation using accuracy, macro-F1 score, and confusion matrices
* Detailed timbre analysis of the erhu, dizi, and guzheng
